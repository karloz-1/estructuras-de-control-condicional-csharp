# 220501097-04-AA1 – EV04 – Aplicación de la sintaxis básica de C# - Estructuras de control condicional.
## Talleres incluidos en este repositorio:

- ### [Reto: Sistema de atención en una clínica veterinaria](https://github.com/karloz-1/estructuras-de-control-condicional-csharp/tree/main/sistema-veterinaria)
    #### Objetivo

    Aplicar todas las estructuras de control condicional de C# (`if-else`, operador ternario, `switch` tradicional y `switch expressions`) dentro de un programa continuo que simula la atención de una mascota en una clínica veterinaria.

- ### [Taller control condicional](https://github.com/karloz-1/estructuras-de-control-condicional-csharp/tree/main/taller-control-condicional)
    #### Objetivo

    Implementar una función que determine si un número es positivo, negativo o cero usando estructuras de control condicional.

## Dependencias:

- [dotnet-sdk-10.0](https://dotnet.microsoft.com/es-es/download)

## ¿Como ejecutar?

1. Clonar el repositorio:

    ```sh
    git clone https://github.com/karloz-1/estructuras-de-control-condicional-csharp.git
    ```

2. Moverse a la carpeta clonada:

    ```sh
    cd estructuras-de-control-condicional-csharp
    ```

3. Entrar a la carpeta de un taller:

    ```sh
    cd sistema-veterinaria
    ```

    o

    ```sh
    cd taller-control-condicional
    ```

4. Ejecutar el proyecto:

    ```sh
    dotnet run
    ```
